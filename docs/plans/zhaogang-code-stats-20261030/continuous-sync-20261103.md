# 本地持续同步层：2026-11-03

用户已选择本地持续同步方案，并确认首次回补从 **2026-01-01** 开始；每 3 小时增量同步。无需追溯更早历史。该方案覆盖此前“进入月份自动全量、当前月 60 分钟刷新”的设计；身份规则及特殊仓库规则继续有效。

## 实施行为

- 统计、明细、成员图表只读取本地持久数据，不在 GET 查询中启动 Git 扫描。月份切换独立于同步进度。
- “立即同步”显式启用当前个人/团队范围的持续同步。已有旧月结果可以直接复用；未同步完成与已同步零提交明确区分。首次启用后由持久任务记录恢复调度，服务无需保持浏览器打开。启动就绪时恢复取消、失败、部分完成或超过 3 小时的已注册范围；新鲜成功结果不重跑，活动任务不重复启动。
- 服务端 `Asia/Shanghai` 的 00/03/06/09/12/15/18/21 点调度已启用范围；活动任务跳过，不重复排队。解绑后使用不到旧令牌；团队任务重新校验发起人成员权限及成员当前凭证，不枚举全部凭证。
- 首次回补一次覆盖 2026-01-01 至今天，而不是按 11 个月分别遍历相同分支。用户显式请求更早日期时可以扩展回补下界，普通查询不会扩展。原有 24 个月保留及查询范围限制仍适用。
- 每仓库持久保存分支名→头 SHA、已验证 SHA 边界、命中提交 SHA 集合。同头分支合并读取，分支组在单 PAT 既有限流下并发。旧版 Redis 月快照不是持续同步的进度来源。
- 头不变且截止范围有效的分支直接复用本地命中记录，**不请求提交列表、不重新拉 diff**。
- 头变化时以不可变 SHA 读取缺失元数据，沿所有父链检查仓库共享图；已验证的祖先闭包直接复用其准确命中集合。合并提交带入的侧链必须读完，不能遇到第一条旧 SHA 就停止。跨日后正常追加仍使用旧边界，不重新从年初读取全部历史。
- 新分支和强推优先复用仓库共享的 SHA 父链，只补未知节点，按新头可达集合重新归属。身份指纹变化、损坏/不适用的进度才需要重新读取相应范围。若已经读到末页，就利用本次结果重建，不再重复拉第二遍。达到分页上限标记部分完成，不发布完整进度。
- 元数据返回后立即按姓名/邮箱身份过滤；未命中作者只保留必要的 SHA 边界，不持久化其姓名、邮箱或提交正文。提交按范围+仓库+SHA 幂等复用，已成功的 diff 不再拉取。`online.base.apijar.service` 仍只统计非合并提交次数，行数为空。
- 仓库全部元数据成功后重建当前分支归属并清理该仓库已不可达/已删除身份的旧行；全年元数据全部成功后清理已不在可见仓库范围内的旧行，diff 不可用不妨碍元数据的可见范围清理。部分失败保留成功数据，并独立保存已读取完整且复核头不变的稳定分支游标，后续只重试缺口。
- 游标保存每头的已验证边界（最多约 256 个/头）、完整命中 SHA 集合和仓库共享 SHA 父链图，压缩持久化。未命中作者只保留 SHA/父链及命中标志。图超过容量保护时先退为头游标；不得发布虚假完整进度。新有效副本保存后清除同仓库旧游标正文，保留历史进度摘要；任务保留清理保护最新订阅、最近成功结果和仍被游标引用的任务。
- 可取消本轮同步，成功记录和已完成仓库的游标保留，定时配置继续生效；取消/中断后可以立即续跑。仓库结束时分别发布已验证稳定分支的进度，不因一个分支变化丢弃整个仓库的进度。中途取消尚未到仓库检查点的部分，下次仍需重读未保存部分。

仍只使用原有 4 张代码统计表，不新增表、不修改凭证表或团队资料。

- `external_zhaogang_code_scan_job`：增加 sync_from、sync_to、sync_team_key、sync_team_host，以及生成列 active_scope_key。后者唯一索引同时保护新/旧任务键格式，范围内只允许一个活动任务。保存上下文不包含令牌。
- `external_zhaogang_code_scan_repo`：sync_state 保存压缩游标；部分失败时仅推进已完整读取且复核稳定的分支，失败分支不冒充完成。
- `external_zhaogang_code_commit`：增加按范围+日期查询索引，供按月本地查询使用。
- 原 POST `/external-service/api/zhaogang/code-stats/scan` 增加 `mode: "SYNC"`；from/to 表示当前展示范围，后台默认回补范围固定为上述起点至今天。FULL 保留为旧接口兼容和人工校验能力。
- scan 响应增加 sync 信息：是否启用、回补范围、最近任务状态/结束时间、下次调度、独立冷却。历史 FULL 的 24 小时冷却不阻止持续增量同步。
- 配置：`iw.external.zhaogang.code-sync-from=2026-01-01`、`iw.external.zhaogang.code-sync-enabled=true`。定时 cron 为每 3 小时整点。旧 current-month-refresh 参数不再驱动页面 GET。
