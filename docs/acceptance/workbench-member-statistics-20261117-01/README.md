# 团队成员统计开关验收

2026-11-17 使用本次构建的 iw-external、隔离 MySQL 8.0 和 Redis、Web 开发服务、两个合成 CODING 账号和预置提交快照。验证团队管理员独占开关权限及全队统一的统计口径。

| 用例 | 结果 | 操作与观察 |
| --- | --- | --- |
| AC-01 初始化与迁移 | 通过 | 新库完整初始化成功。旧库含成员记录，连续两次执行增量迁移均成功，原成员开关值为 `0`。 |
| AC-02 权限与版本 | 通过 | 管理员详情可读取开关，普通成员详情省略该字段。普通成员写入、团队外目标、旧版本和空值均被拒绝。管理员可修改任意当前成员，包括自己。 |
| AC-03 统计口径与缓存 | 通过 | 预先查询并生成缓存后打开开关。管理员和普通成员均只看到剩余成员，工时合计从 11h 变为 8h。月度、缺勤、明细、代码对比和历史提交按新范围返回，直接请求被忽略成员的代码分析和明细均被拒绝。全部忽略时返回空范围，关闭开关后历史提交重新纳入。 |
| AC-04 团队与个人隔离 | 通过 | 同一成员在另一团队可继续纳入工时和代码统计，个人接口仍返回本人 3h 和 1 笔历史提交。 |

| AC-06 企微工时报告 | 自动化通过，真实群未执行 | 采集测试确认跳过被忽略成员及其凭证，通知模块测试确认范围变化后取消待发送报告。显式配置的汇总提醒人独立于缺时提醒。 |
