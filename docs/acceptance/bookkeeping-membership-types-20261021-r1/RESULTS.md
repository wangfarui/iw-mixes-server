## 建议验收

1. 记账设置出现“会员类型”，进入后只有个人管理，没有家庭切换或复制。
2. 新增、改名、启停、删除、排序正常；空名称、重名、超过32字符有提示。
3. 新建订阅只能选择自己启用的类型；没有类型时可进入设置创建，返回后表单内容保留并刷新候选。
4. 已有订阅在类型改名、停用、删除后仍显示原名称；编辑金额或备注不改变类型，主动重选才更新名称；历史名称和“类型待核对”可筛选。
