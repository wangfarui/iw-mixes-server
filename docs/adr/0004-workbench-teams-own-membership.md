# Workbench teams own their membership

找钢工作台使用自己的工作台团队和成员关系，不再把 CODING 团队成员目录作为团队工时的成员来源。CODING 普通成员无法稳定取得团队目录，但真实联调已证明查看者持有其他成员 `userId` 时可以逐成员查询其可见项目范围内的工时；因此工作台持久化成员 `userId` 和资料快照，CODING 继续负责用户身份、顶层团队归属、项目权限和工时事实。

成员必须通过永久邀请链接主动加入，并在加入时校验与工作台团队绑定同一个 CODING `TeamId`。成员名称只能在该成员本人再次访问工作台时自动刷新，团队工时也可能因查看者的项目权限不同而产生不同结果。

每个工作台团队由团队表中的 `administrator_user_id` 指定唯一管理员，管理员必须始终是当前成员；成员表不增加角色或状态。创建人初始成为管理员，但 `creator_user_id` 只保留审计含义。只有管理员可以重命名、移除普通成员、转交管理员和解散团队；普通成员可以直接退出。管理员退出必须在同一事务中先转交给另一名当前成员再删除自己的成员关系，只有管理员一人时只能解散。解散会物理删除团队及全部成员关系，并使固定邀请链接失效。
