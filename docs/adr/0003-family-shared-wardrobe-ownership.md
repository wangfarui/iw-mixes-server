# ADR 0003：家庭共享衣橱采用动态所属人与服务端能力判定

- 状态：Accepted
- 日期：2026-07-29

## 决策

衣物的 `user_id` 表示当前所属人，不表示创建操作人；创建人与最后修改人分别记录在审计字段中。非儿童家庭成员默认可读取家庭有效成员的衣物，儿童和家庭上下文不可用时仅能读取自己的衣物。

所有更新、删除、优化图和图片优化任务操作都必须同时按衣物 ID 与预期所属人约束。所属人变更使用旧所属人作为并发条件，存在活跃图片优化任务时禁止变更。服务端分别返回编辑、删除、优化和标记已穿能力，客户端不自行推导权限。

搭配明细保存衣物快照。再次记录穿着时，服务端先返回已删除或已转交衣物的结构化确认结果；用户确认后才仅使用仍归自己的有效衣物落库。

## 后果

- 家庭组读取失败不会扩大可见范围，而是安全降级到个人衣橱。
- 所属人转移不修改历史搭配和穿着记录的展示快照。
- 普通成员把自己的衣物转交后立即失去维护能力；小程序在提交前明确提示。
- 衣物转回原所属人后可再次用于原搭配；历史快照始终保留用于识别和人工替换。
