# 厨房字典快照迁移（eat_fridge_food / 3010 / 3011）

本目录脚本用于本地或生产**明确授权后**执行。默认不自动运行。

## 顺序

1. `00-preflight.sql`：只读预检，确认结构、模板、重复码名、食材来源可唯一解析。
2. 备份受影响表（`base_dict`、`eat_fridge_food`、相关状态表）与停写相关写入。
3. `01-schema.sql`：增量 DDL（隐式提交），幂等检查定义差异。
4. `02-backfill.sql`：事务内回填快照、审计、一次初始化状态；`READY` 后不再重解析。
5. `03-verify.sql`：断言通过后才接受切换。

## 恢复

保持停写，按备份批次恢复结构/数据与匹配的应用版本。已有新来源写入后不能仅回滚旧 JAR。

## 约束

- 不要使用 `--force`。
- 生产执行、发布需单独授权。
- 本目录不保存备份、原始逐行数据或密钥。
